SITEA - Plataforma Web de Apoio ao TEA

Descrição:
O SITEA (Sistema de Apoio ao TEA) é uma plataforma web desenvolvida para auxiliar os professores do Ensino Médio em como apoiar seus alunos com Transtorno do Espectro Autista nível 1 de suporte.
Essa plataforma permite que o professor gerencie o registro dos seus alunos no ambiente escolar, podendo descrever dificuldades e melhorias apresentadas por cada estudante em sala. Ela também contém materiais de apoio pedagógico organizados por categorias, recomendações baseadas no perfil de cada aluno cadastrado. Cada material podendo conter um questionário opcional, com uma pontuação máxima a ser obtida.
A plataforma possui dois usuários: o Professor e Administrador. O professor podendo consultar os materiais e questionários e registrar cada aluno desejado. O Administrador podendo gerenciar o perfil dos professores e publicar materiais pedagógicos.

Como executar o projeto:
Antes de iniciar precisa ter instalado:
-Node.js e npm
-XAMPP
-MySQL
Visual Studio Code (ou outro editor de código)

Configurar o Bancdo de Dados:
-Abrir o XAMPP
-Iniciar o Apache e MySQL
-Acessar o phpMyAdmin no navegador
-Criar o banco de dados plataforma_tea
-Importar o arquivo SQL no projeto para criar as tabelas necessárias

No terminal:
Na pasta backend:
Rodar 'npm install'
-Configurar o .env com as informações de conexão com o banco de dados
Rodar: npm run dev

Na pasta frontend:
Rodar 'npm install'
Rodar 'npm run dev'
Acessar o endereço mostrado no console
